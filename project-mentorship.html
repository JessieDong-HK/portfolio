连接顶尖名校在读生与申请者的朋辈 mentorship 平台。不做中介、做「过来人」——让真正走过这条路、拿到 offer 的人，用一手经验帮你打破信息差，找到最契合的学长学姐。

Key Features
🎓
Feature 01
朋辈导师网络 · TOP 1% 的过来人

导师来自 Harvard、Stanford、MIT、Oxford、Cambridge、Yale 等顶尖名校，覆盖 6 条申请赛道。他们不是「顾问」，是刚刚走完这条路、拿到 offer 的人——把真实的一手经验讲给你听。

  • 6 条赛道：美本转学 / 美本申请 / 美研申请 / 英联邦 / 高考→海外 / 国内升学
  • 15 位导师起步，Ambassador 模式快速扩张——每个学校 1 位大使，目标 50-100 人
  • 「我行，你也行」：导师分享的不只是方法，还有走过的弯路与真实心态
React Tailwind CSS
🏷️
Feature 02
四维标签 · 精准匹配最契合的学长学姐

学生先选「我想走的路」，再勾「我需要的能力」，从导师池里精准定位到背景高度相似、结果又好的那一位——而不是机构随机塞给你一个「老师」。

  • 赛道（我走过什么路）× 能力（我能帮你做什么）两维平行，交叉筛选
  • 7 大能力域 23 个标签：选校 / 文书 / 推荐信 / 材料 / 学术背景 / 面试 / 心态
  • 活人标签让 mentor 不是「资料卡」，而是一个个真实的人
sql.js Express
🤖
Feature 03
AI 自动生成 Mentor Profile · 标准化 + 自动化

1 小时 coffee chat → 飞书自动建会 → 会后拉逐字稿 → AI 生成 profile 网页 → mentor 本人审核 → 上线。从 outreach 到面试到 profile 生成，全流程自动化，人力只花在「聊」上。

  • 飞书自动创建会议，会后自动拉取逐字稿
  • DeepSeek 把逐字稿结构化生成 profile，mentor 审核后才发布
  • 每个人展示什么信息，完全由本人决定——隐私充分尊重
DeepSeek API 飞书 Open API

不像中介一样大操大办、代写文书。只按「真的帮到你的时间」计费，带你写文书、带你做活动、带你拆申请季——21 世纪拒绝包办。

  • 单次咨询 ¥500/小时：背景评估、文书思路、就读体验、破除信息差
  • 多次咨询包 ¥2200/五次：选校策略 + 活动规划，两位 mentor 合力定制
  • 全包咨询包：从定位迷茫到拿到 offer，全程陪伴

Feature 05
To C 半公益 + To B 机构合作

学生端半公益、赚基础服务费积累案例口碑；机构端（大学 career office / 留学中介）打包出售 mentorship 服务——这才是主要盈利点。
