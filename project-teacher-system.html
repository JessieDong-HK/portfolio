Teacher Standardization

SouthBridge 教师标准化管理体系

把「好老师」变成一套可复制的系统。自研教案、严格培训、全息学生档案、授课逐字稿监督评分——教学质量不押在个别名师身上，而押在体系上。

Python FastAPI SQLAlchemy Jinja2 飞书 Open API Supabase Claude API
Key Features
📝
Feature 01
标准化教案中心 · 自研课件

17 套自研教案覆盖 6 大教学模块。每一节课「教什么、怎么教、留什么作业」都在开课前定好——不是让老师即兴发挥，而是让任何一位通过培训的老师，照着体系就能上出高质量的课。

  • 17 套教案 × 6 大模块：经历挖掘 / 面试训练 / 思辨分析 / 写作 / 圆桌讨论
  • 每份教案含课前准备清单、课中流程节点、课后作业模板，三步到位
  • 区别市面多数机构：先有体系再培训人，而不是招了老师让他自己设计每节课
Jinja2 SQLAlchemy
🎓
Feature 02
严格标准化培训体系

每位老师上岗前走完同一条流水线：研读课件 → 跟课旁听 → 试讲考核 → 达标才接学生。质量不靠「招到好老师」的运气，靠「把普通老师训成好老师」的确定性。

  • 统一培训 + 试讲打分，达标才放行
  • 新老师成长路径标准化，快速复制高质量交付
  • 解决行业通病：不依赖个别名师，规模扩张不掉质量
FastAPI 飞书 Open API
🧑‍🎓
Feature 03
学生全息档案 · 换老师零信息差

一个学生，一份全息档案——基础信息、目标院校、每节课表现、强弱项、进步轨迹，所有模块的老师共享同一份。换老师不换「认知」，针对性辅导无缝衔接。

  • 跨模块老师看到同一份学生档案，优势劣势一目了然
  • 换老师零信息差，新老师接手即懂学生，辅导不断档
  • 针对性辅导：哪项弱就补哪项，而不是「从头再教一遍」
Supabase SQLAlchemy
📊
Feature 04
授课逐字稿 + 监督评分

每节课全程录制，逐字稿自动存档；监督随机抽查、系统化打分。每个老师的交付质量都有数据可查——不靠口碑，靠评分。

  • 全部会议逐字稿永久保存，随时回溯任何一节课
  • 授课评分 + 监督抽查，交付质量持续可控
  • 老师质量可量化、可比较，管理不再是「凭感觉」
Claude API ASR / 逐字稿
